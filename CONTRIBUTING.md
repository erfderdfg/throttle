# Contributing to go-rate-limiter

Thank you for considering contributing!

## How Can I Contribute?

### Reporting Bugs
Search existing issues first. If nothing matches, open a new issue with clear
reproduction steps.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. Write tests for any new logic.
3. Run `go test -v -race ./...` to verify.
4. Submit your PR.
